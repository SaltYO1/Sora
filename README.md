# 空 Sora · N3

Личное веб-приложение для японского N3: функциональный курс из 25 юнитов, карточки, игры, чтение с подсказками.
Чистый JS + CSS без сборки, данные в JSON, прогресс в браузере (IndexedDB), работает офлайн как PWA.

## Структура
```
index.html            оболочка (кнопки «Тема» и «Сохранение» вверху справа)
css/app.css           дизайн-система «вечернее небо над Токио» + стилизованные темы (в конце файла)
js/app.js             маршруты и экраны, тема, сохранение, фуригана/перевод
js/markup.js          разметка v2 (парсер, чтения форм, фуригана) — общая с валидатором
js/render.js tip.js   вывод текста и подсказки
js/data.js db.js      загрузка данных, IndexedDB
js/cards.js fsrs.js review.js   карточки, расписание, сессия повторения
js/quiz.js unit.js    задания и ход урока
js/games.js           игры: собери фразу, на время, скажи иначе, найди кальку
js/words.js           игры по лексике и кандзи: коллокации, чтения, слово в контексте, регистр
js/fluency.js         игры на беглость: скажи быстро, ответь репликой, ответь в чате
js/sky.js             шапка: пиксельное небо (Вечер / Ночь) или сцена темы
js/scenes.js          рисунки шапки стилизованных тем (canvas)
sw.js                 офлайн-кэш (меняй VERSION при изменении оболочки)
manifest.webmanifest  установка на главный экран
data/                 курс, словарь, грамматика, кандзи, юниты, тексты — см. docs/DATA.md
tools/validate.mjs    проверка данных: node tools/validate.mjs
tools/fmt.py          форматирование словаря и кандзи
tools/icons.py        иконки PWA (Pillow)
tools/preview.py      однофайловое превью для claude.ai
```

## Темы
Кнопка «Тема» вверху справа. Выбор хранится в `localStorage sora:theme`.

| id | Название | Вид |
|---|---|---|
| `auto` / `light` / `dark` | Как в системе / Вечер / Ночь | пиксельное небо Токио |
| `aoshingo` | Синий час 青信号 | кобальтовое небо, пешеходный светофор, натриевые фонари |
| `kohaku` | Кохаку 紅白 | кремовая бумага, синяя плитка, карпы, клёны |
| `rock` | Рок-кот ロックンニャー | ретро-афиша: лучи, толстый контур, гитара, кот |
| `showa` | Сёва 昭和レトロ | стена со старыми афишами, эмблема-тако, ржавчина |
| `yokocho` | Хэллоуин 横丁ハロウィン | переулок с красными фонарями, вывески, тыквы |

Новая тема: блок переменных `:root[data-theme="id"]` в `css/app.css` (цвета, `--banner-ink`, `--brand-grad`, по желанию `--sky-frame`, `--grain-bg`),
функция сцены в `js/scenes.js` (`SCENES.id = (g, W, H, {r, bg}) => …`, мотивы справа — слева надпись),
строка в `THEMES` (`js/app.js`) и превью `.sw-id` в CSS.

## Локальный запуск
```
python3 -m http.server 8000   # затем http://localhost:8000
```
Открывать через сервер, а не двойным кликом: модули и service worker не работают с `file://`.

## Публикация
GitHub → Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
Адрес: `https://<логин>.github.io/<репозиторий>/`. На телефоне: открыть адрес → «На экран Домой» (iOS) / «Установить приложение» (Android).
